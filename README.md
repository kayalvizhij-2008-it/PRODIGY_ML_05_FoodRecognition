# 🚀 PRODIGY_ML_05  
## 🍔 Food Recognition & Classification using Machine Learning  

Welcome to my Machine Learning internship project developed as part of the **Prodigy InfoTech Internship Program**. This project focuses on building an intelligent **Food Recognition System** capable of identifying food categories from images using Machine Learning and Computer Vision techniques.

---

# 📌 Project Overview  

Food Recognition is an emerging application of Artificial Intelligence widely used in:
- 🍕 Smart Food Ordering Systems
- 🥗 Health & Calorie Tracking Apps
- 🤖 AI-based Restaurant Automation
- 📷 Image Classification Systems

This project classifies food images into categories such as:
- Pizza
- Burger

using Machine Learning algorithms and image processing techniques.

---

# 🧠 Machine Learning Concept Used  

## 🔹 Image Classification using SVM  

The project uses:
- ✅ Image preprocessing
- ✅ Feature extraction
- ✅ Support Vector Machine (SVM)
- ✅ Food image classification

The model learns patterns from image data and predicts the food category intelligently.
